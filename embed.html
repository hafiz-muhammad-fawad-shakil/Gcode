🔗 Direct Shareable Link

    
Share a GCodex link that automatically loads any publicly hosted G-Code file:

    

      
https://gcodex.tech/?url=https://raw.githubusercontent.com/USER/REPO/main/file.gcode

      
    

    
Replace the URL after ?url= with any public G-Code file URL. Works in GitHub READMEs, forum posts, Discord, and social media.
