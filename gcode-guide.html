Motion Commands

Control machine movement — rapid travel, feed moves, arcs, and homing.

G-Codes
G0

Rapid Positioning

Move at maximum speed — travel moves only, never cutting

 G1

Linear Feed Move

Straight-line move at controlled feed rate F — primary cutting command

 G2

Clockwise Arc

Circular arc interpolation — clockwise direction in active plane

 G3

Counter-Clockwise Arc

Circular arc — CCW, used for climb-milling finishing passes

Coordinate & Position Commands

Set work origins, switch positioning modes, home axes.

Coordinates
G28

Home All Axes

Move to reference / home position — always run before printing

 G29

Auto Bed Leveling

Probe bed surface and build compensation mesh — 3D printers

 G90/G91

Absolute / Incremental

G90 = from zero, G91 = from current position

 G92

Set Position

Redefine current position without moving — reset E axis

Temperature Commands

Control hotend and heated bed temperatures for 3D printing.

M-Codes — Temperature
M104

Set Hotend Temperature

Non-blocking — sets target and continues immediately

 M109

Hotend Temp + Wait

Blocking — printer pauses until target temperature reached

 M140

Set Bed Temperature

Non-blocking heated bed — start heating while doing other setup

Machine Control M-Codes

Fan control, EEPROM, spindle, coolant, and program flow.

M-Codes — Machine
M106

Part Cooling Fan

Control fan speed 0–255 — critical for bridges and overhangs

 M500

Save to EEPROM

Persist all calibration settings across power cycles
